# Day 18 – Python CSV File Handling

## Objective
Learn how to read CSV test data using Python's csv module.

## Concepts Covered
- Importing the csv module
- Using csv.DictReader()
- Reading CSV rows as dictionaries
- Accessing columns using dictionary keys
- Using StringIO to simulate a CSV file
- Counting total test cases

## Practical Application
Read IVR PIN test data and display test case IDs, PINs, and expected results.

## Tools
- Python
- Online Python Compiler

## Result
Successfully read 5 IVR test cases and counted the total number of test cases.
