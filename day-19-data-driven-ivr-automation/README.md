# Day 19 – Data-driven IVR Test Automation

## Objective
Automate IVR PIN validation using external CSV test data.

## Concepts Covered
- CSV data reading
- csv.DictReader()
- Reusable validation functions
- Expected vs actual result comparison
- PASS and FAIL counters
- Automated test execution summary

## Practical Application
Read multiple PIN test cases from CSV data, validate each PIN, and compare actual results against expected results.

## Expected Results
- Total Tests: 5
- Passed: 5
- Failed: 0

## Key QA Concept
A test case passes when the actual result matches the expected result, even if the expected application behaviour is FAIL.
