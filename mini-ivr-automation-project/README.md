# Mini IVR PIN Validation Automation Project

## Project Objective
Build a Python-based IVR PIN validation automation script using data-driven testing.

## Features
- CSV test data handling using csv.DictReader
- Reusable PIN validation function
- Four-digit PIN validation
- Expected vs actual result comparison
- Exception handling
- Automated PASS/FAIL reporting
- Execution summary and pass percentage

## Test Scenarios
- Valid four-digit PIN
- Alphabetic PIN
- Three-digit PIN
- Empty PIN
- PIN with leading zero

## Execution Results
- Total test cases: 6
- Passed: 5
- Failed: 1
- Pass percentage: 83.33%

## Technologies
- Python
- CSV module
- StringIO

## Learning Outcome
Developed a basic data-driven IVR automation project using reusable Python functions and QA validation techniques.
